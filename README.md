# Untuk Azizah ❤️ — OLED Love Animation

A responsive, retro OLED-inspired love page made for Azizah.

## Features
- Animated pixel heart with a retro OLED look
- Twinkling star background and live clock
- Buttons for sending floating hearts, pausing the animation, and creating sparkles
- Responsive layout for mobile and desktop

## Deploy
This is a static HTML site and does not need npm or a build step. GitHub Actions publishes the contents of the repository to GitHub Pages when changes are pushed to `main`.

Expected website URL:
https://fatoniwijaya.github.io/Untuk-Azizah-Dari-Mr.Wijaya-/

If Pages is not enabled automatically, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**.
